PERSONAL, SELF-HOSTED UTILITY

Video

A personal connector between a locally hosted media catalogue and the owner's Google Drive, using rclone. It allows the owner to upload selected files and stream files created by this application.

Access and operation

The connector requests the Google Drive drive.file permission. It accesses files created by, or explicitly made available to, this application. It does not request unrestricted access to the owner's entire Drive.

The connector runs on the owner's computer. This information website does not provide a sign-in form, receive OAuth tokens, serve media, or give visitors access to the owner's files.

This is a private personal setup, not a public media service. Google account access is granted separately through Google's own consent screen.
