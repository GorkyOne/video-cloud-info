Privacy policy

Last updated: 2 November 2026. Applies to this personal, locally operated connector.

Data accessed and purpose

The connector uses Google's drive.file permission to create selected files and read or manage files available to the application. File names, identifiers, sizes, checksums, folder information, and file contents may be processed to upload, verify, catalogue, cache, and play the owner's selected files.

Storage

Selected cloud files are stored in the owner's Google Drive. OAuth credentials and tokens are stored on the owner's computer in the local rclone configuration. Catalogue metadata and playback history are stored locally in the media catalogue. Temporary video data may be stored in a local cache, which can include a complete currently viewed file.

Sharing

The connector communicates with Google Drive for the requested file operations. It does not intentionally publish the owner's files or transmit their contents to this information website, advertising services, or a separate application-operated server. It does not sell Google user data. The local media application may make playback available to devices that the owner explicitly enables.

Retention, deletion, and revocation

The owner controls the local configuration, catalogue, caches, and cloud files. Access can be revoked in the Google account's third-party connections settings. Revocation stops further authorized access; it does not automatically delete existing cloud files, local catalogue records, or cached data. These can be removed separately by the owner.

This information website

These static pages contain no analytics scripts, sign-in form, cookies set by the page, or media files. The website's hosting provider may process ordinary web request information under its own privacy policy. Google services operate under Google's privacy policy. Never enter credentials or tokens into this website.

Personal use

This connector is operated by its owner for their own Google account and is not offered as a public service. The support contact shown on Google's consent screen identifies the project owner.
